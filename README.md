# 🤘 Metal Band App

A web application built with **React** that allows users to explore legendary metal bands, discover their discographies, listen to music through Spotify embeds, and test their knowledge with an interactive **Guess the Riff** game.

## 📖 Overview

Metal Band App is a frontend project created to practice modern React development, API integration, routing, and responsive design while combining music-related content and interactive gameplay.

The application allows users to browse information about some of the most influential metal bands, explore their discographies, and listen to selected tracks through Spotify. It also includes a game mode where users must identify a band based on an audio preview.

---

## 🚀 Features

### 🎸 Band Explorer

* Browse a collection of iconic metal bands.
* View band information, including:

  * Name
  * Genre
  * Country of origin
  * Band image
* Responsive card-based interface.

### 💿 Discography Viewer

* Explore each band's albums and releases.
* Retrieve discography data using the Spotify Web API.
* Display Spotify embeds for selected albums or tracks.
* Listen to music directly from the application through Spotify's embedded player.

### 🎵 Guess the Riff

* Listen to an audio preview clip.
* Choose the correct band from multiple options.
* Generate an engaging music trivia experience using real music samples.

### 📱 Responsive Design

* Mobile-friendly layout.
* Responsive navigation.
* Optimized user experience across different screen sizes.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/metal-band-app.git
```

### Navigate to the project directory

```bash
cd metal-band-app
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
